# Architecture rules
- Keep public demo generation and timing browser-local in DemoFeed, with no operational imports or data connections; demo refinements cannot affect live company workflows.
- Load active-car lists through the shared paginated query, exclude TAKEN both in reads and realtime patches, and keep direct RO/history reads unfiltered; this prevents row-limit omissions without deleting history.
- Merge Park RO lookups without overwriting edited fields or selected locations, and preserve omitted model/notes in the assignment RPC; this prevents location moves from erasing car details.
- Keep ID-based Park loads independent of typed RO corrections and retain the original car identity; delayed lookups must not undo edits.
- Keep Pickup channel lifetimes independent of query-result arrays, read latest context through refs, and ignore statuses after intentional cleanup; this prevents cache updates from triggering reconnect loops.
- Preserve company/RO/date history indexes and the ordered location-snapshot index when changing report queries; they avoid unnecessary scans without dropping history or weakening recovery freshness.
- Use the shared report eligibility predicate before request-based statistics and scoring, including custody lookbacks; this keeps totals, rankings and downstream exports consistent without changing operational history.
- Generate public browser and install icons from the approved wordmark and version their URLs together; this keeps cached icons consistent with the in-app brand.

- Keep experimental company lot previews in isolated frontend-only routes with deterministic mock data until explicit activation; this prevents test layouts from affecting live tenant data or established company maps.
- Keep public customer-arrival writes inside validated server functions scoped by company slug and RO; this prevents one company link from affecting another company's requests.
- Share the pure service-hours validator between customer arrival pages and server writes; this prevents different operating-hour rules across languages or direct requests.
- All Business-page explainer players share one CDN asset pointer and poster; this keeps replacements consistent without oversized repository videos.
- Keep car shortcuts gated by existing Add/Edit capability and guide dismissal scoped to authenticated user IDs; this preserves spectator access and shared-device guidance.
- Request Business video fullscreen synchronously from the initiating gesture, retaining inline/dialog playback when denied; this supports browser restrictions without interrupting the form.
- Only the scheduled database archive completes expired pickup requests using the company's configured window; browser timers must not persist completion, so devices cannot race the archive rule.
- Unlogged-location deductions come only from the shared custody rules in src/lib/unlogged-custody.ts; this keeps one deduction per missed spot across every report.
- Page collection reads with deterministic ordering and scope realtime inserts/updates to the current company; this prevents truncated lists and cross-company patches.
- Store new photo objects under company-qualified paths and authorize legacy paths through company photo records; this prevents duplicate-RO collisions while retaining existing photos.
- Provision the first owner only through the authenticated Support approval flow and transfer ownership atomically; ordinary signups remain pending.
- Define physical exclusivity and blockers through explicit company location rules, retaining JCD's established fallback; never infer exclusivity from arbitrary text.
- Share validated company service hours, RO formats, timezone and report boundaries across client and server paths; defaults preserve existing company behavior.
- Gate every GPS pin-drop, satellite-map and silent-test control through src/lib/aron.ts email checks, and re-verify the caller's email server-side before honoring isTest; this keeps experimental controls invisible and unusable for all other accounts.
- Load the satellite map only through React.lazy from a tap handler; Leaflet imports must never enter the SSR graph.
- Keep GPS sampling and bounded fresh-fix selection in the browser-local GPS tracker, with Park lifecycle cleanup and no polling writes; this limits battery and backend work without promising device accuracy.
- Save GPS location and coordinates together on the car through existing audit triggers, and parallelize only independent request propagation; derive satellite queue pins from visible active requests, including their stored coordinates when a claimed car is TAKEN.
- RO formats are strictly numeric ("digits_1"…"digits_7", default digits_6) via shared roDigitLength/isValidRo/filterRoInput helpers; legacy format values fall back to 6 digits so old company rows keep working.
- Settings, Reports and Flagged Cars access uses the isManagementTitle regex (manager|director|admin) plus the owner; role pickers render regular roles above an unlabeled divider with management titles below.
- The global admin appears as "Huri" in every directory and roster feed, with name, email, role label, avatar and owner badge anonymized at the data-mapping layer.
